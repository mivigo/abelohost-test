# Simple PHP Smarty Blog

Простой, но мощный и функциональный блог на чистом PHP (без использования фреймворков), построенный с соблюдением принципов SOLID, DRY, KISS, YAGNI, стандартов PSR и архитектурных паттернов MVC / Active Record.

## 🚀 Технологический стек
- **PHP**: 8.3+ (с использованием Constructor Property Promotion, `match` выражений и строгой типизации)
- **Шаблонизатор**: Smarty 4
- **База данных**: MySQL 8.0
- **Тестирование**: PHPUnit 10
- **Стандарты PSR**: 
  - PSR-3 (Логирование ошибок)
  - PSR-4 (Автозагрузка классов)
  - PSR-7 (HTTP-сообщения через `nyholm/psr7`)
  - PSR-11 (Собственный DI-контейнер зависимостей)
  - PSR-15 (Собственные обработчики Middleware и Router)

## 🛠 Установка и Запуск

### 1. Запуск окружения в Docker
Запустите контейнеры (Nginx, PHP-FPM, MySQL):
```bash
docker compose up -d --build
```
После запуска проект будет доступен по адресу: **[http://localhost:8080](http://localhost:8080)**

### 2. Установка зависимостей Composer
Выполните установку библиотек внутри контейнера:
```bash
docker exec blog_app composer install
```

### 3. Настройка прав доступа к директории storage
Для корректной работы логирования и кэширования Smarty установите права:
```bash
chmod -R 777 storage/
```

## 💾 Управление базой данных

### 1. Миграции
Для управления структурой БД используется CLI скрипт `migrate.php`:

- **Проверить статус миграций**:
  ```bash
  docker exec blog_app php migrate.php status
  ```
- **Применить новые миграции (up)**:
  ```bash
  docker exec blog_app php migrate.php up
  ```
- **Откатить последний пакет миграций (rollback/down)**:
  ```bash
  docker exec blog_app php migrate.php rollback
  ```

### 2. Сидеры
Для заполнения базы данных демонстрационными данными (7 категорий, 77 постов с уникальными изображениями Picsum, случайным числом просмотров и датами публикации за последние полгода):
```bash
docker exec blog_app php seed.php
```

## 🧪 Тестирование
Среда автотестов использует изолированную базу данных `blog_test_db`. Перед каждым прогоном тестов база данных автоматически очищается и мигрирует с нуля благодаря скрипту автозапуска `tests/bootstrap.php`.

Запустить тесты:
```bash
docker exec blog_app ./vendor/bin/phpunit
```

## 📁 Структура проекта
- `/src` — базовые классы ядра фреймворка (ORM, Router, Container, Logger, Middleware Pipeline).
- `/Controllers` — контроллеры (HomeController, CategoryController, PostController).
- `/Models` — сущности базы данных Active Record (Category, Post).
- `/view` — шаблоны Smarty (.tpl) и Vanilla CSS стили.
- `/migrations` — файлы миграций схем БД.
- `/seeders` — классы наполнения БД данными.
- `/helpers` — вспомогательные трейты и методы (LoggerTrait).
- `/storage` — кэш Smarty, скомпилированные шаблоны и файлы логов.
- `/tests` — модульные и интеграционные тесты PHPUnit.
- `/index.php` — единая точка входа, инициализирующая DI-контейнер и диспетчеризацию запросов.

## 🖥️ Функционал Страниц
1. **Главная страница (`/`)**:
   - Выводит все категории, содержащие публикации.
   - Для каждой категории отображает 3 самых свежих поста.
   - Содержит кнопку «Все статьи» для перехода в конкретную категорию.
2. **Страница категории (`/category/{id}`)**:
   - Отображает название и описание категории.
   - Выводит список всех статей категории в виде сетки по 6 штук на страницу.
   - Поддерживает динамическую сортировку по дате публикации (по умолчанию) и по количеству просмотров.
   - Реализует постраничную пагинацию с сохранением активных параметров сортировки при переходе.
3. **Страница статьи (`/post/{id}`)**:
   - Отображает подробную информацию о посте (дата публикации, счетчик просмотров, категории, текст).
   - Динамически увеличивает счетчик просмотров на 1 при каждом посещении страницы.
   - Выводит внизу блок из 3 похожих статей (имеющих хотя бы одну общую категорию с текущей).
